# ADS Setup Guide

This document provides setup instructions for ad configuration in the NeedA application.

## Ad Networks Supported

- Google Admob
- Facebook Audience Network
- AppLovin

## Configuration Steps

### Google AdMob

1. Create a Google AdMob account at https://admob.google.com
2. Register your app
3. Get your App ID and Ad Unit IDs
4. Add them to your environment configuration

### Facebook Audience Network

1. Create a Facebook Business Manager account
2. Set up your app in the Audience Network
3. Get your Placement IDs
4. Configure in the app

### AppLovin

1. Create an AppLovin account
2. Register your app
3. Get your SDK key
4. Add to configuration

## Implementation

Refer to individual ad network documentation for SDK integration details.
